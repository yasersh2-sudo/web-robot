# Barkeeper Robot

Modern 3D showcase website for the Barkeeper Robot project.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually:

```text
http://127.0.0.1:5173/
```

## Build

```bash
npm run build
```

## Structure

```text
src/main.jsx              Main React page and section components
src/scenes/HeroScene.jsx  Three.js robot bartender hero scene
src/styles.css            Responsive visual system and animations
vite.config.js            Vite React configuration
```

Replace placeholder copy, links, media, and team roles directly inside `src/main.jsx`.
